# D-0001: VoyageSkill v0.1 baseline

- Status: active
- Decider: User
- Decided: 2026-08-13
- Scope: VoyageSkill v0.1
- Supersedes: none

The User approved all recommendations in the v0.1 product and system design
proposal. This decision activates the following baseline:

1. Build a project-level Skill plus a deterministic project-local CLI.
2. Target Codex first while keeping the protocol tool-neutral.
3. Use a JSONL event ledger, JSON definitions, and generated human-readable views.
4. Enforce controllable local resource conflicts; use leases, probes, and gates for external resources.
5. Use project principal IDs and recorded signatures in v0.1 without claiming cryptographic identity assurance.
6. Default to standard risk; allow explicit low-risk compression and require strict handling for high risk.
7. Record User authorization as a scoped, referencable decision event.
8. Limit v0.1 concurrency guarantees to one repository on one machine.

High-risk and irreversible actions remain exclusively subject to final User
authorization. This decision authorizes development; it does not authorize any
production, destructive, paid, credential, or external-write action.
